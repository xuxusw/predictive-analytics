# Датчик контроля процесса обжига в печи

Прогнозирование концентрации целевого продукта (`target`) в реальном времени по минутной телеметрии печи (16 показателей).  
Цель: заменить запаздывающие (10-15 мин) и нерегулярные (в среднем раз в 2 часа) лабораторные замеры оперативным прогнозом, чтобы оператор успевал корректировать режим обжига.

## Данные

| Файл | Описание |
|---|---|
| `data_train.csv` | минутная телеметрия, 16 колонок `telemetry_0..15`, 8 месяцев (01.03-07.10.2019) |
| `target_train.csv` | лабораторные замеры (`Дата`, `target`), нерегулярные, медианный шаг 120 мин |
| `data_test_small.csv` | тестовая телеметрия (следующий месяц, 07.10-04.11.2019) |
| `target_test_small.csv` | тестовые замеры (`Дата`, `target`) |

Все 4 csv должны лежать рядом с ноутбуком.

## Запуск

```bash
pip install -r requirements.txt
jupyter notebook lab2_notebook.ipynb
```

## Этапы:

1. Визуальный анализ телеметрии: тренды, суточная и недельная сезонность, пропуски, выбросы.

2. Анализ целевой переменной: распределение бимодальное (пики около 0.13 и 0.23), скошено вправо, есть нули; частота - медиана 120 мин, максимальный разрыв около 18 суток.

3. Синхронизация источников: `merge_asof(direction='backward', tolerance='2h')`. Все 1773 замера нашли телеметрию в пределах 2 часов.

4. Анализ корреляций с лагами и задержками: выраженного пика именно на 10-15 минутах не обнаружено, связь слабая (максимальная корреляция около 0.19). Для синхронизации фиксируется задержка 12 минут: средняя абсолютная корреляция при 10 и 12 минутах одинакова (0.1331). Выбор не означает, что задержка однозначно доказана только корреляцией.

5. Стратегия обработки пропусков и аномалий: датчики 12-15 исключены из-за 99.34% пропусков. Нули и выбросы не удаляются, а маркируются флагами `is_zero_<sensor>` и `is_outlier_<sensor>` (порог MAD по train). Обоснование: в промышленном процессе нули и экстремумы могут быть реальными режимами, а не ошибками.

## Инжиниринг признаков 
Лаги, скользящие статистики (mean/std/min/max) и признаки динамики формируются по прошлым значениям телеметрии. Всего создано 296 признаков.  
Отбор: удалены 5 низкодисперсных признаков и 22 высококоррелированных признака (corr > 0.995), осталось 269. Сравнение Ridge: CV MAE 0.0794 на полном наборе и 0.0799 после фильтрации - улучшения качества нет. `SelectKBest` удален, поскольку его предварительный fit на всей train-выборке до CV приводил к утечке target из validation-фолдов. PCA не применялся для сохранения интерпретируемости.

## Построение моделей 
Модели: Ridge (L2-регуляризация при мультиколлинеарности), RandomForest (нелинейные зависимости), HistGradientBoosting (градиентный бустинг).  
Ансамбль: равное усреднение Ridge и HistGradientBoosting с bias-коррекцией по OOF-прогнозам.  
Baseline: B1 (среднее по train) и B2 (последнее доступное значение).  
Временное разбиение и `TimeSeriesSplit` без shuffle. Выбор ансамбля выполнен по CV; test не использовался при выборе модели.

## Результаты

### Результаты на TEST (финальная оценка)

| Модель | MAE | RMSE | WAPE, % | DirAcc, % |
|---|---|---|---|---|
| **Ensemble (bias-corrected)** | **0.0577** | **0.0738** | **27.50** | **57.10** |
| Ensemble (raw) | 0.0585 | 0.0736 | 27.91 | 57.10 |
| Ridge | 0.0592 | 0.0761 | 28.23 | 55.84 |
| persist_last_known | 0.0596 | 0.0801 | 28.40 | 34.07 |
| HistGradientBoosting | 0.0611 | 0.0751 | 29.15 | 49.21 |
| RandomForest | 0.0616 | 0.0752 | 29.36 | 53.94 |
| B1 (среднее train) | 0.0803 | 0.0919 | 38.31 | 5.05 |

Ансамбль с bias-коррекцией показал лучший MAE (0.0577) и WAPE (27.50%). MAE ниже baseline_mean примерно на 28.2%. По сравнению с `persist_last_known` преимущество по MAE небольшое (0.0577 против 0.0596). Direction Accuracy - 57.1%, способность определять направление изменений остается ограниченной.

### Анализ остатков ансамбля на TEST

| Проверка | Метод | p-value | Вывод |
|---|---|---|---|
| Нормальность | Shapiro-Wilk | 5.85e-05 | Нормальность отвергается |
| Автокорреляция | Ljung-Box (lag 10 / 30) | 1.86e-25 / 1.74e-26 | Есть выраженная автокорреляция |
| Гетероскедастичность | Breusch-Pagan | 4.29e-05 | Дисперсия остатков непостоянна |

Среднее остатков 0.0067, std - 0.0735. Остатки имеют умеренную правостороннюю асимметрию (skew = 0.582). Автокорреляция снижается с 0.503 у target до 0.378 у остатков, то есть модель устраняет около 25% автокорреляции. Corr(y_pred, |residuals|) = 0.279 - абсолютная ошибка растет с прогнозируемым значением; std остатков увеличивается от 0.0561 в Q1 до 0.0893 в Q4.

### AIC/BIC и скорость

| Модель | AIC | BIC | fit, с | predict на тесте, мс |
|---|---|---|---|---|
| Ridge | **-8659.2** | **-7184.9** | **0.106** | **6.48** |
| RandomForest | - | - | 7.120 | 73.09 |
| HistGradientBoosting | - | - | 2.949 | 10.30 |

AIC/BIC рассчитаны для Ridge. Для RandomForest и HistGradientBoosting эти критерии не приводятся. Ridge - самая быстрая модель; ансамбль использует Ridge и HistGradientBoosting и дает лучшее итоговое качество по MAE и WAPE.

При этом отбор по дисперсии и корреляции сейчас выполняется до `TimeSeriesSplit` на всей train-матрице признаков; для полностью строгой CV-оценки эти фильтры также следует рассчитывать отдельно внутри каждого фолда. Метрики TEST приведены по сохраненному выполнению ноутбука и должны быть повторно получены запуском всех ячеек с исходными CSV.
